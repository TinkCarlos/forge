# Forge 管理控制台设计

版本：1.0　日期：2026-10-21　状态：待评审

> 控制台面向管理员、Agent 构建者、审批人与审计人员。最终用户聊天体验页（P2）不在本文范围。

## 1. 定位与原则

1. **配置即交付**：安装包、Agent、模型、MCP、Skill 的完整生命周期在 UI 完成，不要求改数据库或配置文件。
2. **危险操作可理解**：每个破坏性动作说明影响范围、引用方与恢复方式，并二次确认。
3. **权限可见**：无权限的入口隐藏或禁用并说明原因；所有变更写审计。
4. **状态完整**：每个页面覆盖空、加载、错误、无权限、边界数据。
5. **契约驱动**：表单、校验、错误提示与 API 契约一致；字段来自 `packages/contracts`，不各自发明。
6. **桌面优先**：最小支持 1280px；P1 适配平板；不做移动端管理。

## 2. 技术架构

| 项 | 选型 | 说明 |
| --- | --- | --- |
| 框架 | React 19 + TypeScript + Vite | SPA，构建产物由 API 静态托管 |
| 组件 | Ant Design 5 + ProComponents | 表格、表单、抽屉、步骤条 |
| 路由 | TanStack Router | 类型安全路由、搜索参数 |
| 服务端状态 | TanStack Query | 缓存、失效、轮询、错误重试 |
| 表单 | React Hook Form + Zod | 与 contracts 共用 Schema |
| 动态配置表单 | JSON Schema Form（自研薄封装） | 安装配置、输出 Schema |
| 编辑器 | Monaco | Prompt、YAML、JSON Schema、SKILL.md |
| 图表 | ECharts | 用量、成本、延迟 |
| 流式 | `fetch-event-source` | SSE 续传、退避重连 |
| 身份 | OIDC + BFF + Agent Connector | SSO 会话、角色映射、Connector 状态 |
| 权限 UI | 自研矩阵 + 组织树选择 | 功能权限、数据范围、授权预览 |
| Cron | cron 解析/预览 | 定时任务下次运行时间 |
| i18n | i18next | P0 中文；P1 英文 |
| 测试 | Playwright + axe | 关键流程、可访问性 |

### 2.1 认证与 BFF

- 浏览器经 `/auth/login` 走 OIDC 授权码，API 建立 HttpOnly 会话 Cookie（`Secure`、`SameSite=Lax`）。
- 控制台不把 Token 放 localStorage；所有请求同源。
- 变更请求带 CSRF Token（`/admin/v1/session` 下发），服务端双提交校验。
- 应急管理员登录使用独立入口，强制审计并提示尽快恢复 SSO。

### 2.2 API 客户端

- 由 OpenAPI 生成类型与请求函数，禁止手写重复 DTO。
- 统一错误解析：`{ error: { code, message, requestId, details } }`。
- 429 自动退避；401 跳登录；403 显示权限提示不重试。
- 列表使用游标分页；筛选条件写入 URL，支持刷新/分享。

## 5. 关键流程

### 5.1 安装 Agent 能力包

**入口**：Agents → 安装。

1. **上传/来源**：拖拽 `.forgepkg` 或填 URL；显示文件名、大小、checksum。
2. **预检**：调用 `POST /admin/v1/packages` → `POST /admin/v1/packages/{id}/validate`；展示 manifest 摘要、资源清单、兼容性、签名（P1）、权限（网络/密钥/文件/脚本）。
3. **配置**：按 `config.schema.json` 生成表单；缺失 secret 提供内联创建入口（只写不读）；展示依赖状态（已满足/缺失/可选）。
4. **作用域**：选择全局/组织/角色；显示将影响的用户范围。
5. **Dry-run**：`POST /admin/v1/installations?dryRun=true`；展示创建/覆盖的资源 diff、缺失项、警告。
6. **安装**：`POST /admin/v1/installations`；进入进度页（轮询 `GET /installations/{id}`），步骤：校验 → 依赖 → 资源落库 → 连通性 → 激活。
7. **试运行**：安装完成但 Agent 仍为草稿；提供“试运行”抽屉，输入示例问题，展示工具调用与错误。
8. **发布**：跳转 Agent 详情 → 发布（填写变更说明）→ 按需开启 API。

**失败处理**
- 校验失败：展示错误码、具体文件/字段、修复建议；允许重新上传。
- 依赖缺失：给出安装缺失包/资源的按钮；配置保留。
- 连通性失败：允许“保留但停用”，并提示后续修复入口。
- 安装中离开页面：后台继续，列表显示进度；完成后通知。

### 5.2 新建 / 编辑 Agent

**表单分区**

| 分区 | 字段 | 校验 |
| --- | --- | --- |
| 基本信息 | Key、名称、图标、描述、分类、标签 | Key 唯一、创建后不可改 |
| 模型 | 路由/Provider+Model、温度、最大输出、备用路由 | 能力与输出 Schema 匹配 |
| 指令 | Prompt 编辑器、变量定义、预览 | 必填；变量有默认值；长度限制 |
| 技能 | 多选已发布 Skill、顺序、Token 估算 | 引用存在且启用 |
| 工具 | MCP / OpenAPI / 内置，允许工具列表 | 至少一个工具或明确纯对话 |
| 治理 | 最大步数、成本、审批工具、超时、数据边界 | 成本 > 0；高危工具必须审批或显式豁免 |
| 输出 | JSON Schema 编辑器、示例、修复重试次数 | Schema 合法；示例通过校验 |
| 开放 | 是否开启 API、允许 Scope、速率提示 | 开启 API 需先发布 |

**交互**
- 编辑始终作用于草稿版本；已发布版本只读，可“基于此版本创建草稿”。
- 保存草稿不校验外部连通性；发布前执行完整预检（引用、模型能力、工具、密钥）。
- 试运行可选择“当前草稿”，不要求先发布；结果标记版本来源。
- 发布需变更说明；成功后版本不可变，可回滚（重新发布旧版本）或废弃。
- 离开有未保存修改时拦截确认。

### 5.3 配置自定义模型

**Provider 创建**
1. 选择协议：OpenAI-compatible（默认）、Anthropic-compatible、Azure OpenAI、内置厂商。
2. 填 Base URL、鉴权方式（Bearer/Header/Query）、API Key（Secret 新建）、额外 Header、超时、代理、TLS 校验开关。
3. **测试连接**：调用后端探测；展示状态码、延迟、错误码与建议。
4. **模型目录**：
   - 若端点支持 `GET /models`，一键拉取并勾选；
   - 否则手工添加模型 Key、显示名、上下文/最大输出、能力、价格。
5. **能力声明**：文本、视觉、文件、工具调用、并行工具、JSON Schema、流式、推理。未声明能力在 Agent 发布/运行前会被拦截。
6. 保存 → 创建路由（主模型 + 备用 + 条件）→ 在 Agent 中选择路由。

**规则**
- Base URL 默认必须 HTTPS；内网 HTTP 需管理员在设置中显式允许。
- SSRF 防护与域名白名单；测试连接同样受限。
- 密钥保存后不再显示；只能轮换。
- 价格变更影响后续用量统计，不回溯历史；UI 明示。
- 自定义 Provider 若使用非标准协议，提示需运维安装适配器（P2）。

### 5.4 添加 / 编辑 MCP

1. 选择 transport：
   - **HTTP**：URL、鉴权（None/Bearer/Header/Secret）、超时、健康检查间隔。
   - **stdio**：命令与参数（仅白名单命令）、环境变量（值或 Secret）、工作目录、资源限制。
2. 保存前“测试连接”：协议握手、服务名/版本、工具数、延迟。
3. 工具发现：表格展示名称、描述、入参 Schema、注解、风险；可逐个启用/停用、覆盖风险。
4. 高级：允许网络域名、超时、重试、并发上限。
5. 详情页含健康状态、最近检查、日志（脱敏）、引用该 MCP 的 Agent。
6. 编辑配置会重启连接；显示“进行中调用将排空”的提示。

### 5.5 新建 / 编辑 Skill

1. 安装包或新建：新建时填 Key、名称、描述，生成 `SKILL.md` 模板。
2. 编辑器：Monaco Markdown；frontmatter 表单（名称、版本、允许工具）；正文；资源文件上传/删除。
3. 校验：frontmatter、Key 一致性、引用文件存在、大小、危险路径、脚本声明。
4. 预览：展示将注入的目录条目与正文、估算 Token。
5. 保存草稿 → 发布版本；已被 Agent 引用时展示引用方。
6. 卸载/停用前检查引用；提供“查看受影响 Agent”。

### 5.6 创建开放平台应用与密钥

1. 应用：名称、归属组织、负责人、描述、状态。
2. Scope：勾选 `agents:read`、`runs:create`、`runs:read`、`runs:cancel`、`files:write`；默认最小集。
3. 密钥：名称、过期时间、IP 白名单（P1）；创建后**仅显示一次**，提供复制与下载（P1）；列表只显示前缀。
4. 配额：选择套餐或自定义 RPM、并发 Run、每日/每月次数与成本；显示当前用量。
5. Webhook：URL、事件、Secret（生成/自定义）、启用；提供“发送测试事件”与投递记录。
6. 文档：跳转 `/open/docs`，按应用展示快速开始与示例。

### 5.7 审批

- 列表按待处理/全部、风险、Agent、时间筛选；显示剩余时间。
- 详情：Run 摘要、工具参数（脱敏）、风险原因、调用链、历史决定。
- 操作：批准/驳回 + 评论；并发决定返回 409 并刷新；超时自动驳回显示原因。
- 高风险参数变化（例如金额超阈值）提示重新审阅。
- 决定后事件立即推送；Run 从挂起点恢复。

### 5.8 Run 详情

- 头部：状态、Agent/版本、触发者、耗时、成本、取消/重试按钮。
- 时间线：上下文准备、模型调用、工具调用、审批、压缩、输出校验；可展开。
- 消息：分区查看系统指令、用户输入、工具结果；Markdown 安全渲染。
- 工具：参数/结果（脱敏、截断，大结果提供下载）、耗时、重试次数、幂等键。
- 事件流：SSE 实时追加；断线显示重连状态；支持暂停自动滚动。
- 错误：错误码、用户提示、requestId、复制排障信息。

### 5.9 定时任务

**创建/编辑**
1. 基本信息：名称、描述、Agent（仅已发布）、服务账号。
2. 调度：Cron 表达式 + 时区；实时预览未来 5 次运行；支持常用模板（每天 9 点、每周一 9 点）。
3. 输入：按 Agent 输入 Schema 生成表单/JSON 编辑器；校验大小与必填；不使用生产敏感数据做默认值。
4. 策略：
   - 版本策略：触发时最新已发布 / 固定版本；
   - 并发策略：skip（默认）/ queue / cancel_previous；
   - 最大运行时长与预算（受 Agent/策略上限约束）。
5. 通知：失败连续 N 次通知负责人/管理员（P1 可扩展到 IM）。
6. 保存后默认停用；确认后启用。

**列表/详情**
- 展示状态、下次运行、上次结果、连续失败次数、服务账号、Agent 版本。
- 操作：启用/停用、立即运行、编辑、复制、删除（保留历史上以审计）。
- 立即运行：以服务账号创建 Run；若并发策略为 skip 且已有运行，提示并拒绝。
- 历史：按 Run 状态/时间筛选；失败显示错误码与建议；可跳转 Run 详情。
- 暂停原因：服务账号停用、Agent 停用、权限不足、Cron 非法；显示修复入口。
- 时区/DST：显示下次运行的实际本地时间与 UTC；跨时区用户可切换显示。

### 5.10 功能权限与数据权限

**角色详情**
1. 功能权限 Tab：按域分组勾选；显示将新增/移除的权限；保存前确认。
2. 数据权限 Tab：资源 × 动作 × 范围矩阵；`deny` 高亮；冲突提示“拒绝优先”。
3. 成员 Tab：绑定用户/组，选择全局/组织作用域；组织管理员只能授予自身权限子集。
4. 历史 Tab：变更人、时间、前后值；P1 支持回滚。

**数据范围构建器**
- `org_tree`/`org`：组织树单选；显示包含的子部门数量。
- `custom_orgs`：组织树多选；显示总数与示例。
- `self`/`app`/`service_account`：展示解释与适用范围，不可选组织。
- 保存前检查引用；删除被使用的范围时阻止。

**授权预览**
- 选择用户/服务账号 + 资源类型（Run/Message/File/KnowledgeBase）。
- 展示有效角色、功能权限、数据范围、可见记录数与拒绝原因。
- 不返回消息正文或敏感字段；预览行为写审计。

**服务账号**
- 创建：名称、用途、来源系统（可选）、角色、数据范围、过期时间。
- 展示关联定时任务、最近使用、最后失败；停用前提示影响。
- 不可登录控制台；不可作为 SSO 用户。

### 5.11 SSO 与 Connector

**状态页**
- SSO：provider、issuer、clientId、回调地址、模式（required/optional/disabled）、最近登录成功/失败、角色映射数量。
- Connector：在线实例、配置版本、期望版本、漂移、最后心跳、入站/出站开关、LKG 状态、最近拒绝。
- 操作：
  - 本地 OIDC 模式：编辑 issuer/clientId/secret（只写）、测试登录；
  - Connector 模式：配置由 Agent 管理员签名下发，页面只读；提供“刷新状态”“复制诊断信息”。
- 角色映射：Agent code/name → Forge 角色；只读或按模式可调；保存前校验无访问角色。
- 紧急操作：显示“关闭入站/出站”的方法与负责人；控制台不提供绕过验签的开关。
- 首次接入：展示 checklist 链接与缺失项（SDK 校验、System ID、公钥、缓存卷、开关状态）。

### 6.2 表单与校验

- 客户端即时校验 + 服务端权威校验；服务端错误映射到字段。
- 动态表单由 JSON Schema 生成；自定义 UI 用 `uiSchema`，不写死表单。
- 文本输入长度、URL、Cron、SemVer、JSON Schema、MCP 命令均在客户端做基础校验。
- 保存按钮在提交中禁用；防重复提交；失败保留输入。
- 未保存离开拦截；草稿自动保存仅限 Agent/Skill 编辑（P1）。

### 6.3 状态与提示

- 空态：一句说明 + 主操作 + 文档链接；不显示无意义插画。
- 加载：骨架屏；超过 300ms 才显示；避免布局跳动。
- 错误：`错误码 · 用户提示 · requestId`，提供复制与“查看处理建议”。
- 成功：轻量 Toast；关键操作（发布、安装）显示结果详情。
- 长任务：进度、步骤、可离开；完成通知。
- 破坏性操作：说明影响、需输入资源 Key、不可撤销的明确标注。

### 6.4 可访问性

- 全部表单有 label；错误与字段关联（`aria-describedby`）。
- 键盘可达；焦点可见；抽屉/弹窗焦点陷阱与 Esc 关闭。
- 颜色不是唯一状态表达；对比度 ≥ WCAG AA。
- 图表提供表格替代与文本摘要。

## 7. 权限与错误

- 页面级权限：`agent.view/manage/publish`、`plugin.install`、`mcp.manage`、`skill.manage`、`model.manage`、`apikey.manage`、`run.view.all`、`approval.decide`、`schedule.view/manage/run`、`data_policy.view/manage`、`service_account.manage`、`audit.view`、`org.manage`、`secret.manage`、`settings.manage`、`sso.manage`、`connector.manage`。
- 无权限：列表页不请求敏感数据；详情页显示 403 说明，不泄露资源存在性。
- 所有变更操作在服务端再次鉴权，前端隐藏不是安全边界。
- 错误码映射到可读文案；未知错误显示 requestId 与联系管理员提示。
- 审计：资源详情提供“变更历史”抽屉；敏感字段脱敏。

## 8. 前端工程约定

```
apps/console/src/
  app/                 router、providers、layout、auth
  pages/               路由级页面（薄）
  features/            领域组件与 hooks
    agents/
    skills/
    mcp/
    tools/
    models/
    runs/
    approvals/
    schedules/
    open-platform/
    org/
    roles/
    permissions/
    service-accounts/
    governance/
    settings/
  components/          通用组件
  lib/                 api client、query keys、format、i18n、sse
  styles/              theme、tokens
  i18n/                zh-CN、en-US（P1）
```

- 页面只做编排；数据与交互逻辑放 `features/*/hooks`。
- Query Key 统一：`['agents', filters]`、`['agent', id]`；变更后精确失效。
- 不使用全局状态管理存服务端数据；仅会话/偏好用轻量 store。
- 组件不直接拼 URL；使用生成的 API client。
- 所有用户可见文案走 i18n key，禁止硬编码中文到深层组件（P0 中文资源集中管理）。
- 日期/金额/Token 统一格式化；时区显示用户时区与 UTC 切换（P1）。
- SSE Hook 统一处理 Last-Event-ID、指数退避、页面隐藏时暂停。
- 单元测试组件逻辑，E2E 覆盖关键流程；不在 E2E 中依赖真实模型。
